# B-HU资源检索

帮助用户从B-HU资源库中查找合适的网站、工具和软件资源。该skill维护一个本地资源数据库，定期自动更新，并提供智能的多语言搜索能力。

## 数据来源

- **资源数据**：`https://s.b-hu.org/data/data.csv`
- **分类树**：`https://s.b-hu.org/data/fenlei.md`

## 数据管理

数据存储在此skill目录的 `data/` 子目录下：
```
data/
├── date.txt          # 下载日期（YYYY-MM-DD格式）
├── data.csv          # 资源数据（CSV格式：名称,URL,描述,分类,标签等）
└── fenlei.md         # 分类树（Markdown无序列表+缩进）
```

### 数据更新策略

每次运行时按以下流程处理：

1. **检查 `data/date.txt` 是否存在**
   - 如果不存在 → 首次使用，需要下载数据
   - 如果存在 → 读取日期，检查是否过期

2. **判断数据是否需要更新**
   - 计算距离上次下载的天数
   - 如果超过30天 → 提示用户数据已过期，建议更新
   - 如果data.csv或fenlei.md不存在 → 必须下载

3. **下载/更新数据**（使用web_fetch或curl/wget等）
   
   Windows系统（PowerShell或CMD）：
   ```powershell
   # 使用PowerShell下载
   Invoke-WebRequest -Uri "https://s.b-hu.org/data/data.csv" -OutFile "data/data.csv"
   Invoke-WebRequest -Uri "https://s.b-hu.org/data/fenlei.md" -OutFile "data/fenlei.md"
   ```
   
   或使用CMD的curl（Windows 10+自带）：
   ```cmd
   curl -o data/data.csv https://s.b-hu.org/data/data.csv
   curl -o data/fenlei.md https://s.b-hu.org/data/fenlei.md
   ```
   
   Linux/Mac系统：
   ```bash
   curl -o data/data.csv https://s.b-hu.org/data/data.csv
   curl -o data/fenlei.md https://s.b-hu.org/data/fenlei.md
   ```

4. **更新日期文件**
   - 下载成功后，将当前日期（YYYY-MM-DD格式）写入 `data/date.txt`
   - Windows: `echo 2026-07-13 > data/date.txt`
   - Linux/Mac: `date +%Y-%m-%d > data/date.txt`

## 工作流程

### 步骤1：检查和准备数据

在开始搜索前，先确保数据可用：

1. 检查skill目录下的 `data/` 文件夹是否存在，不存在则创建
2. 读取 `data/date.txt` 获取上次更新日期
3. 判断是否需要下载/更新数据
4. 如果需要更新，使用适合当前系统的命令下载数据
5. 确认 `data.csv` 和 `fenlei.md` 可读

### 步骤2：理解用户需求

仔细分析用户的请求：
- 用户想要什么类型的工具/网站？（如：图片编辑、文件转换、学习资源）
- 有什么特定需求或限制？（如：免费、在线使用、支持某种格式）
- 用户的使用场景是什么？
- 用户偏好的语言（从提问语言判断：简中/繁中/英文）

### 步骤3：构建搜索策略

基于用户需求，制定多轮搜索策略。

**关键词提取**：
- 功能关键词（做什么）：编辑、转换、下载、学习
- 类型关键词（是什么）：图片、PDF、视频、网站
- 特征关键词（怎么样）：免费、在线、开源、简单

**多语言扩展**：为每个关键词准备多语言变体
- 简体中文：图片编辑、软件
- 繁体中文：圖片編輯、軟體
- 英文：image editor, software

**相关词扩展**：考虑同义词和相关词
- 同义词：修图=美化=处理=编辑
- 上位词：图片编辑→图像处理→多媒体工具
- 下位词：图片编辑→抠图、滤镜、调色

### 步骤4：查阅分类树（可选）

如果需要了解资源的组织方式，可以先阅读 `data/fenlei.md`。这有助于：
- 了解有哪些资源分类
- 发现可能相关的类别
- 调整搜索关键词以匹配分类层级

使用grep或findstr快速查看分类：
```bash
# Windows
findstr /C:"图片" data/fenlei.md
# Linux/Mac
grep "图片" data/fenlei.md
```

### 步骤5：执行搜索

使用grep/findstr在CSV文件中搜索关键词。执行多轮搜索以确保覆盖全面：

**重要提示**：CSV文件第一行是表头 `title,description,link,tags`，搜索时要注意。

**搜索命令示例**：

Windows (使用findstr):
```cmd
findstr /I /C:"图片编辑" data\data.csv
findstr /I /C:"image" data\data.csv
```

Linux/Mac (使用grep):
```bash
grep -i "图片编辑" data/data.csv
grep -i "image" data/data.csv
```

**多轮搜索策略**：
1. **第一轮**：使用最直接的关键词（如："图片编辑"、"PDF"、"视频"）
2. **第二轮**：使用相关词和变体（如："图像"、"修图"、"image"）
3. **第三轮**：搜索tags字段中的分类（如："图片处理"、"文件相关"）
4. **第四轮**：如果结果太少，使用更宽泛的词（如："处理"、"工具"）

**搜索技巧**：
- 使用不区分大小写搜索（`-i` 或 `/I`）
- 关键词可能出现在title、description或tags中
- description是HTML格式，可能包含`<p>`、`<br/>`标签，搜索时会一起匹配
- 对每个关键词及其变体分别搜索
- 合并结果并去重（根据link字段）

**解析CSV行的方法**：
由于CSV可能包含逗号，建议使用以下方式解析：
- 每行格式：`title,description,link,tags`
- title：第一个逗号之前
- link：第三个字段（通常是http开头）
- tags：最后一个字段
- description：中间部分（可能包含逗号）

### 步骤6：解析和处理结果

读取CSV搜索结果并解析：

1. **理解CSV结构**：
   - 第一行是表头：`title,description,link,tags`
   - 跳过表头，从第二行开始处理
   - 每行4个字段，用逗号分隔（但description中可能也包含逗号）

2. **提取字段信息**：
   - **title**：资源名称
   - **description**：HTML格式描述，需要清理`<p>`、`<br/>`等标签
   - **link**：资源URL
   - **tags**：分类标签（多个标签用逗号分隔）

3. **清理HTML标签**：
   - description包含HTML标签如`<p></p>`、`<br/>`、`<a>`等
   - 在呈现给用户时，移除这些标签只保留文本内容
   - 空描述`<p></p>`应显示为"暂无描述"

4. **去重**：
   - 根据link字段去重（相同URL只保留一条）
   - 如果同一资源出现多次，保留匹配度最高的

**评分排序**：对结果进行相关性评分
- **title完全匹配**：100分（关键词就是标题）
- **title部分匹配**：50分（标题包含关键词）
- **tags匹配**：每个标签匹配+30分（分类很重要）
- **description出现关键词**：每次+10分
- **优先级调整**：
  - 如果用户明确说"在线"，优先推荐tags包含"在线工具"的
  - 如果用户说"下载"，优先推荐tags包含"下载"的
  - 如果用户说特定学科，优先推荐该学科分类的

根据评分对结果排序，优先展示最相关的资源。

### 步骤7：呈现结果

按以下格式向用户展示结果：

```
根据您的需求"[用户需求摘要]"，我从B-HU资源库中找到以下推荐：

## 🌟 强烈推荐

### 1. [资源名称]
🔗 **链接**：[URL]
📂 **分类**：[分类路径]
📝 **简介**：[描述]
✨ **推荐理由**：[说明为什么特别适合用户需求]

### 2. [资源名称]
...

## 📋 其他选择

### 3. [资源名称]
🔗 [URL] | 📂 [分类]
[简短描述]

### 4. [资源名称]
...

---

💡 **搜索说明**：
- 使用的关键词：[列出使用的关键词和变体]
- 共找到 X 个相关资源
- 数据更新日期：[date.txt中的日期]

🔄 如果这些不符合您的需求，请告诉我更具体的要求，我可以调整搜索策略重新查找。
```

**呈现原则**：
- 前3-5个为最相关的推荐，提供详细信息和推荐理由
- 其他结果简要列出，便于快速浏览
- 如果结果很多（>10个），按分类分组展示
- 如果结果很少（<3个），说明情况并建议调整需求
- 始终告知用户数据的更新日期

### 步骤8：处理特殊情况

**情况1：无结果或结果很少（<3个）**
```
很抱歉，使用关键词"[关键词]"只找到了很少的匹配结果。

让我尝试以下策略：
1. 使用更宽泛的搜索词：[列出备选词]
2. 查看相关分类有哪些资源
3. 或者您可以换个方式描述需求？

例如：
- 是否可以接受类似功能的工具？
- 有什么必须满足的条件？
- 主要用途是什么？
```

**情况2：结果过多（>15个）**
```
找到了 X 个相关资源，为您按分类整理：

### [分类1]
1. [资源名称] - [简短描述]
2. ...

### [分类2]
...

如需更精确的推荐，请告诉我：
- 更具体的使用场景
- 必须具备的功能
- 其他筛选条件
```

**情况3：用户需求不明确**
```
我理解您需要[概括需求]，但为了给您更精准的推荐，我需要了解：

1. 具体用途是什么？
2. 有什么特殊要求？（如：免费、在线、支持中文等）
3. 您的技能水平？（新手/进阶/专业）

或者，我先给您展示几个常见的选择：
[展示3-5个最可能相关的资源]
```

**情况4：数据过期提醒**
```
⚠️ 注意：当前资源数据更新于 [日期]（已超过30天）

建议更新数据以获取最新资源。我现在可以帮您更新数据吗？
- 输入"是"或"更新"：立即更新数据
- 输入"继续"：使用当前数据继续搜索
```

## 搜索示例

### 示例1：图片处理工具

**用户提问**："我需要一个在线图片编辑工具"

**执行步骤**：
1. 提取关键词：图片、编辑、在线
2. 查看fenlei.md，发现有"在线工具 > 图片处理"分类
3. 扩展关键词：
   - 简中：图片处理、图片编辑、图片调整
   - 英文：image、picture、photo
4. 搜索tags包含"图片处理"、"图片调整"的资源
5. 筛选出在线工具类的结果
6. 按相关度排序并展示

**可能的tags**：图片处理、图片调整、图床、排版、图片绘制

### 示例2：古籍文献查找

**用户提问**："哪里可以找到中国古籍？"

**执行步骤**：
1. 提取关键词：古籍、中国
2. 查看fenlei.md，发现有"学科 > 历史相关 > 古籍下载"、"学科 > 中文相关 > 古籍下载"
3. 扩展关键词：
   - 简中：古籍下载、古籍、文献、历史文献
   - 繁中：古籍下載
4. 搜索tags包含"古籍下载"的资源
5. 也搜索description中提到"古籍"、"文献"的资源
6. 按数据库规模和质量排序

**可能的tags**：古籍下载、历史相关、地方馆藏、世界馆藏

### 示例3：文件转换工具

**用户提问**："有什么PDF转Word的工具？"

**执行步骤**：
1. 提取关键词：PDF、Word、转换
2. 查看fenlei.md，发现有"在线工具 > 文件相关 > 文件处理"
3. 扩展关键词：
   - 简中：PDF转换、文件转换、格式转换
   - 英文：PDF converter、convert
4. 搜索tags包含"文件处理"的资源
5. 在title和description中搜索"PDF"
6. 优先展示明确支持PDF转换的工具

**可能的tags**：文件处理、文件相关

### 示例4：学习资源

**用户提问**："推荐一些学英语的网站"

**执行步骤**：
1. 提取关键词：英语、学习
2. 查看fenlei.md，发现有"综合 > 课程/资讯 > 英语"、"学科 > 语言相关 > 英语"
3. 扩展关键词：
   - 简中：英语学习、英语课程、英语教材
   - 英文：English、learning、course
4. 搜索tags包含"英语"、"课程"的资源
5. 按资源类型分类（课程、资料、练习等）
6. 展示不同类型的选择

**可能的tags**：英语、课程、语言相关

## 注意事项

1. **数据时效性**：
   - 始终向用户说明数据的更新日期
   - 如果数据超过30天，提醒用户可能需要更新
   - 如果数据超过90天，强烈建议更新

2. **搜索质量**：
   - 使用多种关键词和语言变体进行搜索
   - 不要只依赖单一关键词
   - 注意繁简体字的差异（如：软件/軟體、在线/線上）
   - 理解用户的语境和真实需求

3. **结果呈现**：
   - 优先质量而非数量
   - 提供推荐理由，而非简单罗列
   - 分类清晰，便于用户选择
   - 始终给用户调整搜索的机会

4. **隐私保护**：
   - 所有搜索在本地完成
   - 不记录用户的搜索历史
   - 不上传任何用户数据

5. **用户体验**：
   - 如果用户对结果不满意，耐心询问具体需求
   - 提供多样化的选择
   - 说明清楚每个推荐的特点
   - 保持友好和帮助性的语气

## CSV数据格式

data.csv文件包含以下4个字段：
- **title**：资源标题/名称
- **description**：资源描述（HTML格式，可能包含`<p>`、`<br/>`等标签）
- **link**：资源链接URL
- **tags**：标签（逗号分隔，可能有多个，如"古籍下载, 历史相关"）

**注意**：
- description字段是HTML格式，搜索时需要考虑HTML标签
- tags字段包含分类信息，非常重要用于匹配
- 某些资源的description可能为空`<p></p>`

## 为什么这个skill很有用

B-HU资源库是一个精心维护的工具和网站集合。这个skill通过智能搜索帮助用户：

- **节省时间**：无需在海量网站中盲目搜索，直接获得精选推荐
- **精准匹配**：基于分类、描述和标签进行多维度匹配
- **多语言支持**：无论用中文还是英文提问，都能找到合适资源
- **本地化搜索**：快速响应，保护隐私
- **持续更新**：定期同步最新资源，保证推荐的时效性
- **分类清晰**：通过分类树帮助用户理解资源组织
- **多样选择**：提供不同类型和难度的选项供用户选择
